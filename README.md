## 📖 Overview

Welcome to the repository for **Apoorv Gaur's** personal portfolio website.

This project marks the author's very first hands-on software release. Coming from a foundational background in **Java** and **Python**, this portfolio was intentionally engineered without heavy frameworks or build dependencies. The goal: to master the fundamental building blocks of the web—**HTML5, modern CSS3, and Vanilla JavaScript**—from the ground up.

Visitors can explore the author's background, current technical skill set, active learning roadmap, and direct contact channels.

---

## ✨ Key Features

- **🌓 Dynamic Theme Engine:** Seamless dark and light mode toggle with persistent state saved via browser `localStorage`.
- **📱 Fully Responsive Layout:** Mobile-first architecture designed to adapt fluidly across handheld devices, tablets, and widescreen displays.
- **⚡ Zero Dependencies:** Fast load times and 100% native browser support with no external frameworks or libraries.
- **🎨 Modern Aesthetic:** Glassmorphism headers, subtle gradient accents, and curated typography using Google Fonts (*Inter* and *Fira Code*).
- **📬 Interactive Communication:** 
  - Integrated contact form with automatic web Gmail dispatch.
  - One-click email copy-to-clipboard with real-time feedback.
  - Direct links to GitHub and LinkedIn profiles.
