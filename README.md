## 🚀 How to Run Locally

Because this is built with clean HTML, CSS, and JavaScript:

1. Simply **double-click `index.html`** in this folder.
2. It will open immediately in your web browser! No terminal or installation needed.

---

## 📤 How to Upload to GitHub as Your 1st Contribution

Follow these steps in your terminal inside this folder:

### 1. Initialize Git & Make Your First Commit
```bash
git init
git add .
git commit -m "My first ever contribution: Personal Developer Portfolio"
```

### 2. Connect to Your GitHub Repository
1. Go to [GitHub](https://github.com) and create a new repository named `portfolio` (leave it public and empty).
2. Run these commands:
```bash
git branch -M main
git remote add origin https://github.com/ApoorvGaur31/portfolio.git
git push -u origin main
```

---

## 🌐 How to Make It Live on the Internet (Free GitHub Pages)

Once pushed to GitHub:
1. Open your repository on GitHub (`https://github.com/ApoorvGaur31/portfolio`).
2. Click **Settings** (top right tab).
3. In the left sidebar, click **Pages**.
4. Under **Branch**, select `main` and click **Save**.
5. Within 1 minute, your portfolio will be live at:  
   👉 `https://apoorvgaur31.github.io/portfolio/`
